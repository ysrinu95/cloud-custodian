## Overview

Cloud Custodian is an open source compliance-as-code tool used to promote well-managed cloud infrastructure, optimize cost, and promote security.

* Website: [https://cloudcustodian.io](https://cloudcustodian.io)
* Repo: [cloud-custodian](https://bitbucket.org/greenstreetadvisors/cloud-custodian)
* Contact: CloudAdmin@greenstreet.com or #squad_devops on Slack

## Accounts

Cloud Custodian is currently deployed into the following accounts:

* Development
* Staging
* Production
* Shared
* Audit
* Log
* Root
